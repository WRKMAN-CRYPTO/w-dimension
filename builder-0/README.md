# Builder-0: W Field

The first Builder AI experiment.

Builder-0 does **not** attempt intelligence. It asks one narrower question:

> Can a population-controlled W field become causally useful to a population of simple agents?

## Experiment 0

Two worlds run side by side from the same seed and identical initial agents.

- **W-LIVE**: agents write a local W field, sense it, carry internal W state, and W contributes to steering.
- **W-NULL**: agents still write and carry W so it can be observed, but W has no causal effect on steering.

Both worlds contain the same simple task: agents can collect energy at the source and deliver it to the sink. The agents are not told to build structures. There is no neural network, no evolution, no language model, and no global controller.

The first useful measurement is deliberately boring: energy delivered.

If W-LIVE does not reliably outperform W-NULL across controlled seeds, W has not earned a larger role.

## Rules

1. Determinism first. Seeded PRNG and reproducible starting state.
2. W must be causal in the experimental arm and inert in the control.
3. Instrument before interpreting.
4. Do not reward behavior for looking intelligent.
5. Preserve failed experiments.
6. A pretty pattern is not evidence. Interventions come next.

## Planned interventions

If Experiment 0 produces a repeatable difference:

- freeze W
- scramble W
- erase recurring W structures
- transplant W between populations
- replay from snapshots
- expand from one seed to seed batches

Builder-0 is intentionally small. The ocean can stay dark until the instruments say there is something in it.
